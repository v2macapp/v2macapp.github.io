# V2Mac website

Source of [v2macapp.github.io](https://v2macapp.github.io), the site for [V2Mac](https://github.com/v2macapp/v2mac), the native Xray and V2Ray client for Mac, its Secure Sandbox, and [NoLeaker](https://github.com/v2macapp/noleaker). Built with Astro and three.js, deployed to GitHub Pages.

```sh
npm ci
npm run dev
npm test
```

The release notes and download link come from V2Mac's GitHub releases at build time. Plan and design decisions: [docs/PLAN.md](docs/PLAN.md).
